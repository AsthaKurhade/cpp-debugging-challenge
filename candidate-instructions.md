# C++ Debugging Challenge — Round 2

## 1. Overview

Welcome to Round 2 of the C++ Debugging Challenge.

You will be given multiple C++ programs based on programming,
problem-solving, algorithms, and Object-Oriented Programming concepts.

The programs intentionally contain multiple bugs.

The number of bugs in each program is **NOT disclosed**.

Your goal is not only to make the program compile, but to understand
the intended logic, identify the problems, fix them, and verify that
the corrected program works correctly.

---

# 2. Your Task

For every assigned question, you must:

1. Read and understand the complete program.
2. Compile the program.
3. Run the program using the provided test cases.
4. Identify the bug(s).
5. Point out the exact location of each bug.
6. Explain why each bug is incorrect.
7. Fix the bug(s).
8. Compile and run the corrected program.
9. Verify the output against the expected behavior.
10. Identify additional edge cases.
11. Explain the changes you made.
12. Give time and space complexity where applicable.

---

# 3. Important Rule

The number of bugs is intentionally **NOT provided**.

Do not assume that finding one error means the program is completely fixed.

A program may contain:

- Compilation errors
- Syntax errors
- Logical errors
- Runtime errors
- Incorrect conditions
- Incorrect boundary conditions
- Incorrect algorithm implementation
- Incorrect use of C++ features
- Object-oriented design errors

You are expected to inspect the **entire program**.

---

# 4. Debugging Process

Follow this process for every question.

### Step 1 — Understand

Before changing the code, explain:

- What is the program supposed to do?
- What algorithm or concept is being used?
- What should the expected result be?

---

### Step 2 — Compile

Compile the original program.

Record any compiler errors or warnings.

Do not immediately rewrite the entire program.

---

### Step 3 — Run

Run the program using the supplied test cases.

Observe:

- Incorrect output
- Runtime errors
- Unexpected behavior
- Program termination
- Incorrect calculations
