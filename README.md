# C++ Debugging Challenge — Round 2

## Overview

This repository contains a set of C++ debugging challenges designed to
evaluate programming knowledge, problem-solving ability, debugging skills.


## Candidate Task

For each program:

1. Read and understand the code.
2. Compile and run the program.
3. Identify all bugs.
4. Point out the exact location of each bug.
5. Explain why the code is incorrect.
6. Fix the bugs.
7. Run the corrected program.
8. Verify the output.
9. Identify possible edge cases.
10. Give the time and space complexity where applicable.
11. Explain what was changed.

## Important

Do not assume that the first error you find is the only error.

A program may contain multiple independent bugs.

Candidates are expected to test their corrected solutions.

## Rules

- Do not rewrite the entire program unless necessary.
- Try to identify and fix the existing bugs.
- Explain your reasoning before making changes.
- You may use the compiler/debugger.
- You should be able to justify every modification.
