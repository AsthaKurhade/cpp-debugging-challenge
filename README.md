
# C++ Debugging Challenge — Round 2 CESA ACM

Welcome to **Round 2 of the C++ Debugging Challenge**.

This round is designed to evaluate your ability to read, understand,
debug, test, and explain existing C++ programs.

The programs are based on programming fundamentals, problem-solving,
algorithms, and Object-Oriented Programming.

---

## 🎯 Objective

You will be given C++ programs containing multiple hidden bugs.

Your task is to:

- Understand the intended purpose of the program
- Identify the bugs
- Locate the exact source of each bug
- Explain why each bug is incorrect
- Fix the bugs
- Compile and test the corrected program
- Check additional edge cases
- Explain your changes
- Analyze time and space complexity where applicable

> **The number of bugs in each program is intentionally not disclosed.**

Do not stop after finding the first error.
